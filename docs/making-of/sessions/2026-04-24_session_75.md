## Ce qui a été fait

Session marathon de polish mobile portrait + déploiement itch.io. Le jeu est passé
d'un build mobile utilisable à un build mobile vraiment propre et jouable sur
téléphone dans un iframe itch.io.

### Gros morceaux
- **Tailles des boules uniformisées** : avant, chaque type de boule (acier,
  bronze, chrome...) héritait de son `rayon` dans boules.json, ce qui donnait
  3 tailles visuelles différentes (variation de 22%). Maintenant toutes les
  boules utilisent `BALL_RADIUS` — uniforme visuellement et physiquement.
- **Sprites des joueurs au terrain** : passés de scale 0.65 à 1.0, alignés
  précisément dans le cercle de lancer (pieds sur le bord inférieur du rond).
- **Menus mobile** : refonte portrait de QuickPlay, Shop, PlayerScene, ResultScene.
  Boutons 56-88px (WCAG), layouts verticaux empilés.
- **Auto-fullscreen itch.io** : au premier tap sur mobile, le jeu passe plein
  écran automatiquement via `requestFullscreen()`. Fini le cadre autour.
- **Orientation lock portrait** sur Android, overlay "retournez votre téléphone"
  sur iOS qui ne supporte pas l'API lock.
- **Rangement du repo** : archives/ et AssetPetanqueMasterFinal/ déplacés dans
  docs/archive/. Racine du projet nettoyée.

## Moments forts

- **Le bug ZIP Windows** : après upload sur itch.io, le jeu refusait de se lancer
  (écran marron fixe). Console : 403 sur tous les `.js`. Cause : PowerShell
  `Compress-Archive` créait des entrées avec backslashes (`assets\index.js`)
  au lieu de forward slashes. Régénéré avec JSZip → jeu fonctionnel.
- **Le bug portrait sur PC** : après déploiement, le jeu se lançait en portrait
  même sur PC dans l'iframe itch.io. Cause : la détection `innerWidth < 800 &&
  orientation portrait` se déclenchait parfois. Fix : ajout du check
  `pointer: coarse` (touch-only) pour éviter les faux positifs.
- **Superposition instinct/boule** : dans PlayerScene, les labels des abilities
  (y=304) et le nom de la boule équipée (y=304) se chevauchaient en portrait.
  Corrigé en resserrant les abilities et en poussant la boule.

## Décisions notables

- **CHAR_SCALE_PETANQUE passé de 0.65 à 1.0** : le user a explicitement demandé
  plein taille (128px), pas un entre-deux. Les sprites remplissent mieux l'espace
  sur mobile.
- **Rayon du cercle de lancer 16→28px** : il faut que le cercle soit proportionné
  au sprite du lanceur, sinon visuellement le perso "flotte" au-dessus du rond.
- **Mode figé au boot** (Layout.js) : pas de recalcul au resize, car l'orientation
  lock + overlay landscape couvre 99% des cas. Refacto live trop lourde pour
  un gain minime.
- **Bottom nav TitleScene retirée** (fin de session) : redondante avec les 4 cards
  du menu principal (Arcade, Quickplay, Persos, Shop). Mobile = menu simple.
