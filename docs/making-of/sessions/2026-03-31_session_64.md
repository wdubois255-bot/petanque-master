## Ce qui a ete fait

C'est une session de preparation au lancement. Pas une ligne de code de jeu — 100% strategie marketing et outillage de publication.

**Audit complet de l'etat reel :**
La session a commence par un constat brutal : les docs de lancement etaient remplis d'erreurs. "6 techniques" (il y en a 3), "440 tests" (il y en a 3011), "12 personnages" confirmé (chai et la_loutre ne comptent pas), "FR 95%" (c'est 100%), et le commentateur mentionné 3 fois alors qu'il a ete supprime le 30 mars. Tout a ete corrige dans ITCH_IO.md, ITCH_IO_quickwins_revenus.md, et LANCEMENT_ITCH_FINAL.md.

**Recherche approfondie :**
Analyse de ce qui se fait sur itch.io et CrazyGames : patterns de conversion, outils disponibles, techniques pixel art. Resultat : un plan complet en 7 etapes (PLAN_ASSETS_ITCHIO.md) qui codifie exactement comment produire des assets de qualite professionnelle.

**Premiere tentative de captures automatiques (v1 ratee) :**
Deux scripts crees : capture-itch-assets.mjs (Playwright) et generate-cover-art.mjs (Sharp). La cover art v1 etait correcte (composition pixel art avec Papi Rene, Mamie Josette, VS, boule, cochonnet). Mais les screenshots etaient quasi identiques — le tutoriel in-game bloquait l'ecran dans tous les cas. La navigation par clavier ne fonctionnait pas en mode headless SwiftShader. Le GIF automatise etait robotique.

**Le vrai plan v2 :**
Les scripts sont maintenant corriges pour utiliser Playwright en mode `headless: false` (GPU reel), bypasser le tutoriel via localStorage apres le goto, et injecter les scenes directement via `game.scene.start()`. La cover art sera basee sur une capture de la VSIntroScene (qui a deja une composition dramatique pro : split diagonal, deux persos face a face, "VS" en or) plutot que d'un fond plat.

## Moments forts

- **La confrontation avec les chiffres** : lire les docs et realiser que presque tout etait faux (6 techniques, 440 tests, commentateur fantome) avant que la description aille sur itch.io — ca aurait ete embarrassant.

- **La cover art v1** : voir les sprites de Papi Rene et Mamie Josette cotes a cotes avec le badge "VS" rouge, rendus en pixel art pur, fonctionne deja visuellement. La base est la.

- **La decouverte de la VSIntroScene comme couverture** : la scene de VS intro du jeu est deja une composition marketing en soi. Split diagonal bleu/rouge, personnages face a face, texte "VS" geant en or. C'est exactement ce qu'on aurait construit a la main.

## Decisions notables

- **12 personnages** (pas 14) : chai et la_loutre sont dans characters.json mais pas dans le roster jouable. Confirm par l'utilisateur.
- **Photopea API = inutile** pour ce projet : Sharp fait deja tout ce qu'on a besoin, sans lancer un navigateur headless pour acceder a un site web.
- **SwiftShader = a bannir** pour les captures marketing : le mode headed avec GPU reel est obligatoire pour que le jeu ait le meme rendu que ce que voient les joueurs.
- **VSIntroScene comme base cover art** : plutot que de composer depuis zero, capturer l'ecran VS qui est deja une composition dramatique et y ajouter un overlay titre.
