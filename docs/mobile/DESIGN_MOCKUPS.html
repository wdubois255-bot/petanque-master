Démo « Claude Design » — Petanque Master portrait mobile

Ce fichier est un exemple de livrable que Claude Design produirait en quelques prompts conversationnels à partir de ton codebase. Il montre une refonte des 5 scènes clés en portrait 480×960 respectant ta palette provençale, tes conventions de taille (boutons 56px+ WCAG), et les ancres définies dans src/utils/Layout.js.

Valeur démonstrée : au lieu d'itérer coordonnée par coordonnée dans Phaser pour chaque scène, un mockup comme celui-ci sert de source de vérité visuelle. Chaque agent Sonnet qui attaque une scène (Phase 2 polish) a un référent pixel-précis à reproduire. Gain estimé : ~50% de temps de polish, et cohérence globale garantie.

Ce qui manque dans ce fichier vs Claude Design réel : export Figma/PDF/PPT, édition live par conversation, extraction automatique du design system depuis le codebase, capture web du produit existant. Ici c'est du HTML/CSS statique fait main pour illustrer.

Ouvre ce fichier dans ton navigateur : docs/mobile/DESIGN_MOCKUPS.html. Les 5 cadres 480×960 ci-dessous simulent un écran mobile portrait.

Workflow réel avec Claude Design

1. Extraction design system — Claude Design lit src/utils/Constants.js (palette COLORS), public/data/characters.json, les sprites et détecte automatiquement ocre #D4A574, terracotta #C4854A, olive #6B8E4E, etc. Il propose ensuite des composants (bouton bois, panel ombré, carte perso).

2. Conversation itérative — « Redessine la TitleScene en portrait mobile 480×960 en gardant le gradient ciel/ocre ». Claude Design produit une version interactive, tu commentes inline (« le logo trop bas », « je veux 4 boutons pas 6 »), il ajuste en direct.

3. Export spec — chaque élément a ses coordonnées, tailles, couleurs exactes. Un agent Sonnet lit la spec et produit le code Phaser correspondant en une passe au lieu de 5 itérations.

4. Pitch / marketing — le même outil génère la fiche itch.io visuelle, les slides pour Poki/CrazyGames, les banners social media. Tout dans la même identité visuelle.

Limite connue : Claude Design ne génère pas des sprites pixel art (rester sur PixelLab) ni du code Phaser (rester sur Claude Code). C'est un outil de conception visuelle, pas de production asset ni d'implémentation.
