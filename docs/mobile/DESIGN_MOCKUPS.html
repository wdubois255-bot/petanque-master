Mockups portrait v2 — Petanque Master (démo Claude Design)

Version 2 avec rendu visuel enrichi : sprites personnages SVG (vue de dos), textures terrain procédurales (bruit SVG), ombres en couches, gradients multi-stops, bords arrondis iOS-style, notch smartphone stylisé, palette provençale affinée, typographie Impact + SF Mono.

Changement structurel principal — marge watcher passée de 96px à 50px. Le terrain en match fait désormais 380 × 850 (scale ~2.11) dans un écran 480×960, soit 88.5% de la hauteur. Les sprites adversaire (watcher) sont positionnés sur le bord du terrain, moitié visible dans la marge 50px, moitié chevauchant le terrain — plus dynamique et "plein écran".

Impact physique côté code — scale 2.11 > 1.6 actuel. La vitesse visuelle augmenterait (+31%). Deux options d'implémentation :
• Scale physique 2.11 + réduction MAX_THROW_SPEED de 15% pour compenser (garde la distance métrique identique mais ralentit la perception).
• Scale visuel seul : terrain rendu en 380×850 mais zone de physique interne reste 288×672, avec conversion coord physique → rendu par facteur 1.32 (plus complexe mais physique 100% préservée).

Workflow réel avec Claude Design

1. Extraction design system — Claude Design lit src/utils/Constants.js (palette COLORS), public/data/characters.json, les sprites v2_new, et détecte automatiquement la palette provençale et tes conventions (boutons bois, panels ombrés).

2. Itération conversationnelle — « J'ai changé d'avis, marge watcher 50px au lieu de 96px ». Claude Design recompute toutes les scènes en live, tu valides à l'œil, il exporte les specs finales pour chaque élément.

3. Code generation — les specs sortent en JSON structuré (position, taille, couleur, type de composant). Un agent Sonnet (Claude Code) lit le JSON et génère le code Phaser en une passe — plus d'itérations aveugles sur les coordonnées.

4. Marketing multi-supports — le même design system génère : fiche itch.io, bannière CrazyGames, slides pitch Poki, posts social media. Tout reste cohérent visuellement.

Limites pour notre jeu : Claude Design ne génère pas de sprites pixel art 32×32 (PixelLab reste le choix), ni de code Phaser 4 (Claude Code reste le bon outil). C'est un outil de conception visuelle, pas de production d'assets ni d'implémentation.
